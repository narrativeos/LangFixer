Features

From fixing this sentence to eliminating this class of mistakes.

After detection it answers "why does this error happen" and "how to fix it for good"; feedback you accept becomes training data, so capability grows from your domain's data, not from model scale.

🔍

Detection

Chinese, English and Japanese. The rule layer runs fully offline — if external tokenizer services are unreachable it degrades to local dictionaries and rules. Lexicons are external JSON: extend them without recompiling, plus domain glossaries that prevent false corrections.

🧭

Attribution

ZEN decision tables (GoRules JDM standard) emit error labels, Weiner's three dimensions (locus × stability × controllability), CEFR A1–C2 difficulty and remediation steps — every decision traceable.

📚

Knowledge base

Import a knowledge source → mine knowledge points → derive decision-table rules → publish after human review. End-to-end self-learning from a single book is productized.

🎓

Teaching

Personalized LLM explanations (prompts per language × CEFR level) plus a mistake notebook with FSRS review — a complete learning loop.

🔄

Training flywheel

Accepted corrections become training samples; at threshold the feature model retrains, a dev-set eval gate blocks regressions, and the new model hot-swaps — the LLM long tail keeps shrinking.

🖼

Document review

Review images, PDFs and Word files directly: annotations are overlaid on the original and never modify it, with expert correction sheets replayable and exportable for editorial and publishing workflows.

🖥

Offline desktop

A Tauri 2 desktop app that runs fully offline; an Axum API server (Dockerized) plus a Vue 3 web app — desktop and server share one core engine.

🔐

Local & private

Individuals run it offline on their own machine; teams self-host inside their network, tailoring lexicons, glossaries and knowledge rules to their domain. Your text never leaves the boundary by default.

Positioning

In industry terms, it comes down to two words.

Capability grows from accumulated domain data, not from stacking model scale.

A self-learning flywheel

A full loop of detect → feedback → reflection → training → evaluation: accepted corrections flow into training samples automatically; at threshold the model retrains and hot-swaps if the dev-set gate sees no regression. "Better with use" is an architectural property, not a slogan.

Local and private

The desktop app is fully offline; the server form is self-hosted. Rules and the feature model run on your machines, and text goes out only when you explicitly configure an LLM endpoint. The gateway's logging policy has a hard line: user text is never recorded.

Straight talk

What it cannot do.

We do not claim full recall.

  • On the Chinese document-review gold set the local rule layer has 0% recall — the real capability boundary is each language's lexicon coverage and the benchmark reports from the eval center; see MULTIMODAL.md in the repository.
  • Japanese detection is at an early stage; English is the most mature; Chinese covers dictionary-rule categories (homophone and look-alike typos, de-particle usage, punctuation spacing, time-format mixing and more).
  • LLM review and explanations require your own endpoint and budget; the offline rule layer is unaffected when none is configured.
  • It is not a style editor — it corrects errors, it does not rewrite or polish your content.
