# 界面改造方案 v2（布局与交互彻底重做）

> 范围升级:在 v1(IA 重构)基础上,**视觉语言、布局骨架、交互载体全部重建**,只继承
> 数据契约(REST/Tauri 命令)、caps 门控语义与 `labels.ts` 人话词表。
> 依据:macOS HIG([desktop-hig.md](desktop-hig.md) 已登记两处偏差,本方案修复其一)、
> Web UI 通用规范(可访问性、8pt 网格、焦点可见、减少动态)、frontend-design 设计规范。
> 仍不动:后端 API、鉴权模型、IP 边界。

## 0. 现状为什么"凑合"——对照规范的逐条判定

| 症状 | 证据 | 违反的规范 |
|---|---|---|
| 顶栏平铺 10 个导航钮,按 caps 逐钮显隐 | App.vue header-nav;desktop-hig.md「明确取舍」自认与 Mac 惯例偏差 | HIG §4:侧边栏是导航主面;顶栏只放高频命令 |
| 常规操作用模态弹窗 | 16 处 `el-dialog`、48 处 `el-alert` 常驻提示 | HIG §7.3/反模式 6:常规反馈用行内状态,弹窗只留给不可逆决策 |
| 万物皆卡片 | 107 处 `el-card`,运营页=等高圆角卡片阵列 | 布局即信息:卡片阵列不表达层级,是模板套件特征 |
| 控件尺寸按 Web SaaS 默认 | EP 默认控件 32–40px 高 | HIG 反模式 4:Mac 控件 22–28pt 紧凑 |
| 表格默认密度 | 64 处 `el-table` + 270 列,无密度/行选中规范 | HIG §6.6:行选择、⌘/⇧多选是 Mac 肌肉记忆 |
| 用 tab 页掩盖 IA | 规则管理 3 tab、知识维护 2 tab、进化中心内部 tab | HIG 反模式 3:分区用侧栏/分节标题,不用 tab 堆 |
| 错误提示是 Mood 不是指引 | 502/503/403 直接透出 `e.message` | 界面文案规范:错误必须说明发生了什么+如何补救 |
| 层级术语在 UI 里漂移 | labels.ts 已修一轮,但来源徽章/置信度/管线三套话术仍并存 | 词汇即路标:同一概念全界面同名 |

结论:问题不在 token(现有明暗 token 是合格的),在**组件载体与布局骨架**。因此重建载体、沿用并扩展 token。

## 1. 设计语言

**概念:校样(Proof Sheet)。** 产品本质是编校工作台——被校文字是主角,界面是安静的
审校台。整个设计只在**校样标记**上用力,其余克制。

- **色彩**(沿用现有语义 token,重划用途):
  - `paper`/`ink`(现有 surface/text 系)构成审校台底色——冷调纸白,不是米黄;
  - **红笔红 `--danger` 从此只有一种含义:错误标记**,chrome、装饰、强调一律不用红;
  - 交互主色维持品牌靛 `--primary`;层级徽章(本地检查/快速定案/知识查询/AI 复查)
    用中性灰阶+字重区分,不引入彩虹色——层级是来源属性,不是重要度属性;
  - 桌面端交互强调色向系统强调色靠拢为后续项(Tauri 侧暴露 accent),先以品牌靛统一。
- **字体**:两族分工——
  - **UI chrome = 系统字体栈**(SF Pro/PingFang,HIG §9.1),基准 13px,Mac 密度;
  - **校样画布 = 中文衬线栈**(Songti SC / Noto Serif CJK 回退):被校文本与界面
    chrome 用字族直接区分,呼应纸质校样传统;这是衬线唯一出场处,UI 标题不用衬线。
  - 字阶 12/13/15/18/22,字重不超过常规/中等/加粗三档。
- **布局**:8pt 网格(HIG §9.6);工具栏一体式标题栏 52px;控制台侧栏 220–260px
  可折叠;**控件高度 28px(Mac 紧凑档),表格行高 32px**;阴影只出现在浮层
  (popover/menu/toast),卡片不再有假阴影。
- **动效**:唯一编排时刻=「应用修正」时原文→修正文的 diff 形变;其余瞬时切换;
  尊重 `prefers-reduced-motion`。
- **文案**:沿用 labels.ts 人话词表为唯一词汇源;CTA 动词与结果提示同词
  ("发布"→"已发布");错误/空态一律带下一步指引;不用全大写标签、不用装饰性眉题。

## 2. 壳与骨架

### 2.1 工作台(默认壳,macOS 一体式工具栏)

```
┌──────────────────────────────────────────────────────────────┐
│ ●●●  LangFixer        [快速|标准|深度]      ● 服务 4/4  ⌕ 🔘 │ ← 52px 工具栏:
│          文稿名 · 语言 zh▾                    状态chip 搜索  │   分段控件=检测深度
├──────────────────────────────────────────┬───────────────────┤
│                                          │ 检查器 Inspector  │
│        校样画布(衬线,校样标记)          │  默认=摘要+层级轨迹│
│   ~~混淆~~ ∧漏词 ⸜标点⸝ per error kind  │  点错误=切到该条   │
│        hover 标记 = 浮出改错对           │  归因/CEFR/讲解    │
│                                          │  [采纳] [加入错题本]│
├──────────────────────────────────────────┴───────────────────┤
│ ▸ 底部抽屉:历史/错题本(⇧⌘H 开关,拖放文件到此)              │
└──────────────────────────────────────────────────────────────┘
```

- 检测深度 = 工具栏分段控件(HIG §3.3 视图切换用分段控件),每档下方一行说明实际走哪几层;
- **检查器**取代右列结果卡片流与弹层:摘要态显示层级轨迹条(规则 N₁→L3 定案 N₂→AI 复查 N₃),
  点任一错误,检查器即该条的归因详情——讲解流式渲染在检查器内,静态回退明示;
- 校样标记系统:删除线=替换、插入号=缺词、波浪线=搭配、点线=标点,红色系深浅表置信
  (把握大/中/小沿用 labels.ts);采纳后标记淡出+diff 形变一次;
- 文档审校/载体审校是同一画布的不同「文稿来源」(工具栏 ⌘O/拖入),不再三个平级入口。

### 2.2 运营台(侧栏壳,HIG §4)

```
┌──────────┬─────────────────────────────────────────────┐
│ 侧栏     │  内容区(分区标题 + 表格/列表,非卡片阵列)  │
│ 知识与规则│  ─ 决策表:行表格,行内编辑+⌘↵试算+版本弹层 │
│  ·决策表  │  ─ 词表/规则开关:密度表格+行 hover 启停    │
│  ·词表    │  进化中心                                  │
│  ·知识点  │  ─ 左:进化时间线(导入/发布/重训练留痕)    │
│  ·资源包  │  ─ 右:待纳队列 / 测评报告 / 飞轮状态       │
│ 进化中心  │  质量透明(各层贡献,评审可读)              │
│ 质量透明  │  服务与设置(按热更新组分节,即时生效标注)  │
│ 服务与设置│                                           │
└──────────┴─────────────────────────────────────────────┘
```

- 侧栏条目=caps/identity 门控的单一判定 `viewAllowed()`,不再模板逐钮 v-if;
- 运营台内部不再用顶栏按钮+子 tab;分区=侧栏条目,页内分区=节标题;
- 表格全面重做:行高 32px、⌘/⇧ 多选、行右键菜单(桌面原生,Web 自绘)、搜索进工具栏右侧(HIG §3.4);
- 对话框配额:仅发布确认、删除资源包(先自动导出备份的说明)、回滚确认三处;其余用
  行内展开、检查器、toast;toast 3 秒内消失且带「撤销」位。

## 3. 组件策略:自建 primitives,逐步退役 Element Plus

EP 的交互骨架(弹窗 Everything、卡片 Everything、默认密度)与上述规范冲突,且是
「凑合感」的来源。但不做整仓大爆炸:

| 自建原语(~14 个) | 替代 | 备注 |
|---|---|---|
| Toolbar / SegmentedControl | header 按钮流 | 一体式工具栏 |
| Sidebar / SectionHeader | 顶栏导航+el-tabs | 单一门控判定 |
| DataTable | el-table ×64 | 密度/多选/右键/排序/虚拟化 |
| Form(Row/Field/Select/Switch) | el-form ×30 | 28px 控件、行内校验 |
| Inspector / Popover / Menu | el-dialog/alert 大部分 | Esc 即关(HIG §10) |
| Toast / Badge / Tag / Mark | el-message/el-tag ×246 | 校样标记是独立组件 |
| Stepper / Progress / Timeline | el-progress/alert | 导入向导+进化时间线 |

- 迁移期新旧并存:`src/ui/` 自建层 + EP 仅存未迁视图;每迁完一个视图删一块 EP 引用;
- P4 终点:package.json 移除 element-plus 与 icons,包体预计显著下降;
- 现有 415 行 token 文件扩展为 `tokens.css`:补控件高度/表格密度/字阶/焦点环/对比度增强档;
- 可访问性基线一次到位:焦点环全局可见、`prefers-reduced-motion`、WCAG AA 对比度、
  图标钮一律 aria-label、`labels.ts` 成为屏幕阅读器文案源。

## 4. 分期实施

| 期 | 内容 | 验收 | 风险 |
|---|---|---|---|
| P0 骨架 | 双壳导航(工具栏+侧栏)+ 视图注册表 + 深链兼容;EP 原样 | 旧 `?view=` 全通;桌面 View 菜单⌘1-7 同步 | 低 |
| P1 设计系统 | tokens.css 扩展 + 14 个原语 + 明暗/减少动态/焦点审计 | 原语库快照测试;对比度脚本检查 | 中 |
| P2 工作台 | 校样画布+校样标记+检查器+深度分段+底部历史抽屉 | 三语 L1/L2/L3 轨迹正确;⌘Enter/⌘Z/Esc 全通;明暗两态走查 | 高(核心体验重写) |
| P3 运营台 | 侧栏分区+DataTable 替换+进化时间线+对话框清零 | 导入向导五步/资源包三操作/决策表版本回滚回归 | 中高 |
| P4 退役 | 删 EP;lib 测试矩阵(深链×caps×identity) | package 无 element-plus;bundle 对比留档 | 低 |

每期独立发布;桌面形态每期同步 macOS 走查(工具栏/右键/拖放/快捷键/HIG 清单见 desktop-hig.md,新增「侧栏替代顶栏导航」并撤销该条「明确取舍」)。

## 5. 明确不做

不重写后端与 API;不做多窗口(维持 desktop-hig.md 的既录取舍);不做移动端与浏览器
兼容层;不改网关鉴权;米黄底+大衬线、暗黑霓虹、毛玻璃炫技等模板化视觉一律不采用。
